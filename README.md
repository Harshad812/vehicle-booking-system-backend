# Vehicle Booking System

This is the backend service for the Vehicle Booking System.

## Prerequisites

- Node.js
- Git

## Backend Setup

### 1. Clone the Backend Repository

```bash
git clone <backend-repo-url>
cd <backend-project-folder>
```

### 2. Install Dependencies

```bash
npm install
```

## API Endpoint

Once the backend server is running, you can access the API at:

```
http://localhost:5001/api/v1
```

## Development

Once the setup is complete, your backend server should be up and running. You can now start developing or testing the API endpoints.
